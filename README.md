# Тренажер формул по физике

Приложение для Windows (WPF).

---

## Описание

Интерактивный тренажер для изучения и проверки знаний физических формул. База разделена по темам:

- Механика
- Молекулярная физика и термодинамика
- Оптика
- Квантовая физика
- Ядерная физика
- Электричество и магнетизм
- Колебания и волны

Внутри — несколько режимов:

- **Обучение** — просмотр всех формул с названиями
- **Тренировка** — тест с выбором правильного ответа
- **Запоминание** — появление формулы с задержкой для самопроверки
- **Экзамен** — ограничение по количеству вопросов и распределение по темам

> Главное — учиться в своём темпе и доверять своим знаниям.

---

## Управление

| Клавиша / действие | Функция |
|--------------------|---------|
| Мышь | Выбор режима, ответов и навигация по интерфейсу |
| `Esc` / `✕` | Закрыть приложение |
| `⬅` | Вернуться в главное меню |

---

## Примечание

Результаты экзаменов сохраняются в истории с датой, временем и процентом выполнения.

---

## Инструкция по установке

1. Скачайте архив с релизом.
2. Распакуйте в любом месте (подойдёт 7-Zip).
3. Готово! Запускайте `PhysicsTrainer.exe`.

---

## Требования для запуска проекта

- Windows 10/11
- .NET Framework 4.7.2+ (или среда выполнения, указанная в релизе)
- Visual Studio (для сборки из исходников)

---

## Используемые технологии

- C# / WPF
- WpfMath — рендеринг формул
- Newtonsoft.Json — хранение истории
