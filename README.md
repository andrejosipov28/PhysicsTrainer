Тренажер формул по физике
Дипломный проект. Приложение для Windows (WPF).

Описание
Интерактивный тренажер для изучения и проверки знаний физических формул. База разделена по темам: механика, молекулярная физика и термодинамика, оптика, квантовая физика, ядерная физика, электричество и магнетизм, колебания и волны. Внутри — несколько режимов: обучение с просмотром формул, тренировка в формате теста, режим запоминания с задержкой появления формулы и экзамен с ограничением по количеству вопросов и распределением по темам.

Главное — учиться в своём темпе и доверять своим знаниям.

Управление
Мышь — выбор режима, ответов и навигация по интерфейсу

Esc / ✕ — закрыть приложение

⬅ — вернуться в главное меню

Примечание
Результаты экзаменов сохраняются в истории с датой, временем и процентом выполнения.

Инструкция по установке
Скачайте архив с релизом.

Распакуйте в любом месте (подойдёт 7-Zip).

Готово! Запускайте PhysicsTrainer.exe.

Требования для запуска проекта
Windows 10/11

.NET Framework 4.7.2+ (или среда выполнения, указанная в релизе)

Visual Studio (для сборки из исходников)
